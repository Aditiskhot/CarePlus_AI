# CarePlus_AI
AI-based smart patient queue and virtual waiting system for single-doctor clinics.

## 📌 Project Overview
CarePlus AI solves long wait times and crowded waiting rooms in small and single-doctor clinics. Instead of static queue tokens, CarePlus AI provides dynamic, AI-predicted consultation wait times and virtual waiting capabilities.

---

## Key Features
* 📱 **Smart Digital Tokens:** Scan QR code to check in and receive a token.
* ⏱️ **AI Wait Time Prediction:** Dynamic wait estimates powered by machine learning.
* 🏃 **Virtual Waiting:** Step away from the clinic until your turn approaches.
* 🚨 **Emergency Priority:** Dynamic queue recalculation for high-priority cases.
* 👨‍⚕️ **Doctor Dashboard:** Automated patient notifications via WhatsApp/SMS.

---

## 🛠️ Technology Stack
* **Frontend:** Flutter / React
* **Backend:** Python FastAPI
* **Database:** Firebase / MySQL
* **AI / ML Model:** Scikit-learn (Wait Time Prediction)
* **Notifications:** WhatsApp / SMS Integration

---

## 🔄 How It Works
1. **Check-In:** Patient scans clinic QR code to get a digital token.
2. **Prediction:** ML model estimates consultation arrival/wait time.
3. **Virtual Wait:** Patient waits elsewhere comfortably.
4. **Live Updates:** Queue timing updates dynamically in real-time.
5. **Notification:** Patient is alerted when their turn is near.
